## Présentation

Recettes SkyHand et crafts vanilla désactivés (remplace CustomCrafting).

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shcustomcrafting` | `/shcc` | Recharge les recettes. | `shcustomcrafting.admin` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shcustomcrafting.admin` | Recharger les recettes. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
